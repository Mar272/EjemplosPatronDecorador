# Ejemplos del Patrón Decorador en C#

Este repositorio contiene tres ejemplos prácticos del **Patrón de Diseño Decorador**, desarrollados en C#.

## Estructura del repositorio

### 📁 `Main`
Contiene el **Ejemplo 1: Sistema de Mensajes**  
Implementa un sistema donde se puede aplicar compresión, cifrado y firma a un mensaje de forma dinámica utilizando decoradores.

### 📁 `Ejemplo2`
Contiene el **Ejemplo 2: Sistema de Pizzas**  
Permite construir una pizza base y decorarla con ingredientes adicionales (como queso, pepperoni, etc.), incluyendo la opción de seleccionar tamaños.

### 📁 `Ejemplo3`
Contiene el **Ejemplo 3: Personaje de Videojuego**  
Permite decorar un personaje base con habilidades especiales como escudos, velocidad, etc., añadiendo dinámicamente funcionalidades.
